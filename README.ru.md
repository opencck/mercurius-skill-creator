# mercurius-skill-creator

Встроенный скилл [Меркурия](https://github.com/opencck/mercurius): как агент создаёт и дорабатывает свои скиллы. Он
берёт замысел из беседы, спрашивает только недостающее, пишет короткий SKILL.md с файлами для подробностей,
проверяет черновик на 2–3 настоящих запросах со скиллом и без него через `delegate_task`, настраивает описание, чтобы
скилл срабатывал где нужно, и сохраняет его через `skill_save` в папку собеседника или проекта.

Текст скилла — на русском, языке агента по умолчанию.

## Состав

| Файл | Что это |
|------|---------|
| `SKILL.md` | Когда создавать скилл, порядок работы, как писать |
| `references/anatomy.md` | Поля `skill_save`, ограничения, постепенное раскрытие, скелет |
| `references/testing.md` | Проверка черновика на запросах со скиллом и без |
| `references/description.md` | Описание скилла и проверка срабатывания |

## Подключение

Меркурий подключает его сабмодулем в `skills/skill-creator`; встроенные скиллы читаются при старте и доступны
везде; изменённая копия в папке собеседника или проекта важнее по имени.

```sh
git submodule update --init --depth 1 skills/skill-creator
```

Основан на идеях скилла `skill-creator` из плагинов Claude от Anthropic (замысел, расспрос, проверка со скиллом и
без, настройка описания) и правилах оформления скиллов hermes-agent, переложенных на инструменты и папки Меркурия.
